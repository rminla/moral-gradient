## Edits to call logs (`calls/`)

- Removed `provider_request_id` from every row.
- Removed the provider response `id`, Groq's `x_groq.id` and `system_fingerprint` from each raw response.
- Removed every `signature` field (Anthropic's encrypted thinking signatures). These are opaque blobs with no readable content. Without them, logged Claude conversations can't be replayed to the Anthropic API as continuations, but every readable field is intact.
- Everything else, including the full request messages, tool definitions, raw outputs, token counts, costs and timestamps, is unchanged. With these logs present, the offline rebuild matches the archived bundle exactly.

## Not included, on purpose

- API keys, `.env` files and any credential. The harness reads keys from environment variables only; `registry.json` names the variables but holds no values.
- The cost ledger database (`data/ledger.sqlite`). It mixes this run with unrelated internal runs. Every v3final call and its cost is already in the call logs.
- Raw console logs from the run.
- Data from the development iterations (v3a to v3d) and smoke tests. Those runs informed the method and are summarized in `harness/v3/ITERATIONS.md`, but they are not part of the locked result.
- Anything from the website's database: donor or subscriber emails, sign-in tokens, payment records.

## Scenario content

Every customer, business, account number and invoice in the scenarios is fictional. Names that models wrote in their replies, such as sign-offs, were generated by the models.
